# 📐 Guide : Créer les Documents Graphiques Manquants pour l'APS

## 🎯 Contexte

Pour un APS complet et professionnel, il manque les **documents graphiques** :
- Plans de masse cotés
- Plans d'étage
- Coupes principales
- Façades et élévations
- Perspectives 3D

Ce guide explique comment les créer avec **Plan to 3D House**.

---

## 📋 Documents à Créer

### 1. Plans de Masse (Échelle 1/500)

**Objectif** : Montrer l'implantation du bâtiment sur le terrain

**Étapes** :

1. **Ouvrir l'éditeur**
   ```
   Ouvrir editor.html dans le navigateur
   ```

2. **Dessiner le terrain**
   - Utiliser l'outil "Terrain"
   - Tracer les limites de la parcelle
   - Ajouter les cotes (longueur, largeur)
   - Indiquer le nord

3. **Positionner le bâtiment**
   - Utiliser l'outil "Bâtiment"
   - Placer le bâtiment sur le terrain
   - Respecter les reculs (limites, voirie)
   - Ajouter les distances aux limites

4. **Ajouter les éléments contextuels**
   - Voirie existante
   - Arbres, végétation
   - Bâtiments voisins
   - Réseaux (eau, électricité)

5. **Cotation et annotations**
   - Cotes générales (dimensions terrain)
   - Cotes de position (reculs)
   - Surface de terrain
   - Surface d'emprise au sol
   - COS (Coefficient d'Occupation des Sols)

6. **Exporter**
   - Menu : Fichier → Exporter → Plan de masse
   - Format : PDF haute qualité
   - Échelle : 1/500

---

### 2. Plans d'Étage (Échelle 1/100)

**Objectif** : Montrer la distribution des pièces

**Étapes** :

1. **Dessiner les murs extérieurs**
   - Utiliser l'outil "Mur extérieur"
   - Tracer le contour du bâtiment
   - Épaisseur : 30 cm (isolation incluse)

2. **Dessiner les murs intérieurs**
   - Utiliser l'outil "Cloison"
   - Tracer les séparations entre pièces
   - Épaisseur : 10-15 cm

3. **Ajouter les ouvertures**
   - Portes : outil "Porte"
   - Fenêtres : outil "Fenêtre"
   - Baies vitrées : outil "Baie"

4. **Définir les pièces**
   - Utiliser l'outil "Pièce"
   - Nommer chaque pièce (Séjour, Chambre, etc.)
   - Indiquer les surfaces

5. **Ajouter les équipements**
   - Mobilier : cuisine, salle de bains
   - Sanitaires : WC, lavabo, douche
   - Escaliers si plusieurs niveaux

6. **Cotation**
   - Cotes des pièces (longueur, largeur)
   - Cotes des ouvertures
   - Surfaces des pièces
   - Surface totale habitable

7. **Exporter pour chaque niveau**
   - RDC : Plan RDC
   - Étage 1 : Plan Étage 1
   - Combles : Plan Combles (si applicable)

---

### 3. Coupes Principales (Échelle 1/100)

**Objectif** : Montrer les hauteurs et la structure

**Étapes** :

1. **Choisir les plans de coupe**
   - Coupe longitudinale (dans la longueur)
   - Coupe transversale (dans la largeur)
   - Passer par les escaliers si possible

2. **Dessiner la coupe**
   - Utiliser l'outil "Coupe"
   - Tracer la ligne de coupe sur le plan
   - Le logiciel génère automatiquement la vue en coupe

3. **Vérifier les éléments visibles**
   - Murs (épaisseur visible)
   - Planchers (épaisseur dalle)
   - Toiture (pente, charpente)
   - Ouvertures (fenêtres en coupe)
   - Escaliers (marches, rampes)

4. **Cotation verticale**
   - Hauteur sous plafond : 2,50 m
   - Hauteur totale : variable selon toiture
   - Niveaux de planchers
   - Hauteur des ouvertures

5. **Annotations**
   - Nom des pièces
   - Matériaux (béton, bois, etc.)
   - Pentes de toiture
   - Isolation

6. **Exporter**
   - Format : PDF
   - Inclure cartouche (nom, échelle, date)

---

### 4. Façades et Élévations (Échelle 1/100)

**Objectif** : Montrer l'aspect extérieur

**Étapes** :

1. **Générer les 4 façades**
   - Façade Nord
   - Façade Sud
   - Façade Est
   - Façade Ouest

2. **Pour chaque façade**
   - Utiliser l'outil "Élévation"
   - Sélectionner la face à afficher
   - Le logiciel génère la vue

3. **Vérifier les éléments**
   - Ouvertures (fenêtres, portes)
   - Matériaux de façade
   - Toiture (débord, pente)
   - Éléments architecturaux (balcons, loggias)

4. **Cotation**
   - Hauteur des ouvertures
   - Hauteur totale du bâtiment
   - Largeur des façades
   - Niveaux (RDC, étage, toiture)

5. **Annotations**
   - Matériaux (enduit, bois, pierre)
   - Couleurs (nuancier RAL)
   - Types de menuiseries
   - Détails architecturaux

6. **Exporter**
   - Format : PDF
   - Une page par façade

---

### 5. Perspectives 3D

**Objectif** : Montrer le projet en volume

**Étapes** :

1. **Configurer la vue 3D**
   - Ouvrir la vue 3D
   - Choisir l'angle de vue (vue d'oiseau, vue humaine)
   - Ajuster l'éclairage (soleil, ombres)

2. **Vues extérieures**
   - Vue générale du bâtiment
   - Vue depuis la rue
   - Vue depuis le jardin
   - Vue aérienne (si pertinent)

3. **Vues intérieures**
   - Séjour (vue depuis l'entrée)
   - Cuisine (vue ouverte sur séjour)
   - Chambre principale
   - Salle de bains

4. **Rendu**
   - Mode : Photoréaliste
   - Qualité : Haute (300 DPI)
   - Format : JPEG ou PNG
   - Résolution : 1920x1080 minimum

5. **Annotations**
   - Ajouter le nom du projet
   - Ajouter la date
   - Ajouter le logo (si applicable)

6. **Exporter**
   - Format : Images haute qualité
   - Inclure dans l'APS (annexe)

## 🎯 Résultat Attendu

Un APS complet avec :
- ✅ 6 pages de texte (générées automatiquement)
- ✅ 1 plan de masse
- ✅ 2-3 plans d'étage
- ✅ 2 coupes
- ✅ 4 façades
- ✅ 4-6 perspectives 3D

**Total** : ~20 documents graphiques

---

## 💡 Conseils

1. **Commencez par les plans** (masse + étages)
2. **Enchaînez avec les coupes** (plus rapides)
3. **Terminez par les façades** (basées sur les plans)
4. **Gardez les perspectives pour la fin** (plus longues)

**Temps estimé** : 4-6 heures pour un projet complet
